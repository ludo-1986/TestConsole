## 🛠️ Installation

- [x] Create a parent directory and clone the repository.

```bash
# Standard Terminal
mkdir app
cd app

# ZSH Terminal
mkcd app

# Clone via HTTPS (standard)
git clone https://github.com/ludo-1986/TestConsole.git
# Or clone via SSH
git clone git@github.com:ludo-1986/TestConsole.git

cd depot
```

- [x] Create and activate the Python virtual environment.

```bash
# Create and activate Python venv
python3 -m venv .venv
source .venv/bin/activate
```

- [x] Install the dependencies.

```bash
# Upgrade pip
python3 -m pip install --upgrade pip

# Install requirement.txt
pip install -r requirements.txt
```

## 🚀 Run Python Terminal

```bash
python "file_name".py
```
